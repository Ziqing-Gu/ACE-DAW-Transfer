Install and convert a score

For Windows x64, Apple Silicon and Intel Macs. Extract the bundle first, then open the installer for your platform.

SystemInstall and launch
Windows x64Double-click the Windows x64 .msi. Open ACE-DAW Transfer from the Start menu.
macOS 15 or laterOpen the macOS .pkg and follow Installer. It selects the component for your processor. Launch ACE-DAW Transfer from Applications.

Choose your language

Select 中文 or English in the upper-right corner. Labels update immediately. Your project and output folder stay selected, and the language is restored next time.

Move a score from ACE to Nuendo

Start with the project you have already saved in ACE Studio.

  1. Drop its .acep file into the window or choose Browse file….
  2. Choose Nuendo project (.npr) under Output format. The output folder defaults to the source project folder. Use Browse folder… to change it.
  3. Select Convert, then Open output folder. Open the generated NPR in Nuendo. For Cubase, choose CPR in the previous step.
The converter reads saved files on disk and can run with the DAWs closed. Each conversion gets its own output folder.

Track and marker colors

A new native project can store up to 40 distinct colors; further colors use nearby palette entries. Native writeback uses the original project palette. When XML is imported, the receiving project determines the colors on screen.

Why is the palette project empty?

A custom-color XML export may include 配色导入底板.npr. Open it and import the XML from the same folder as a track archive. To open the score in one step, choose CPR or NPR in the converter.

Send an edit back to your DAW

Save the edited ACEP and drop it into the converter. Keep transfer-map.json and the original project so the converter can write matching fields back to a native source. Changes to the editing structure can be exported as a new arrangement.

Audio, media and recovery

When reviewing a picture edit, check the first and last cuts, a muted clip, a fade and a marker. Audition the plug-in chain in the receiving host.

Media and missing files

Compatible WAV and video files are referenced in place. When moving between computers or operating systems, transfer the assets and make their paths accessible. Relink missing media in the source project and save it again. Conversion, comping or rendering can create new audio inside the output folder.

Timing, levels and fades

Audio events keep absolute placement, duration and source offset. Track level, event gain, event mute and default S-curve fades are stored separately. Each editable default fade uses 1,025 points. The supported workflow uses constant tempo, 4/4, a 48 kHz project and 24 fps video.

Three DAW-to-ACE options

Render non-default fades writes supported curves into separate audio. Transfer compatible static mix settings and edits reports unsupported automation, bus routing and processing; playback can change. Save recoverable VST3 presets separately lets you restore edits before handling effects. These choices persist.

Plug-ins and diagnostics

Third-party VST3 transfers depend on matching component identity, local scan records, licenses and external assets. File checks cover supported timing, media and parameters. Audition plug-ins and hardware routes in the destination. For a conversion problem, read the log and the JSON report in the output folder.

The macOS package is not Apple-notarized. The Windows MSI has no publisher certificate. Get the bundle from the project releases. If macOS cannot verify the developer, see Apple’s guidance on opening downloaded apps.
