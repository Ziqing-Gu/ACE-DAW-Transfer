安装与首次转换

适用于 Windows x64、Apple Silicon 和 Intel Mac。请先解压统一安装包，再运行适合本机的安装程序。

系统安装与启动
Windows x64双击 Windows x64 的 .msi。安装后，从开始菜单打开 ACE-DAW Transfer。
macOS 15 或更高版本双击 macOS 的 .pkg 并按安装器提示操作。安装器自动选择芯片架构。安装完成后，在“应用程序”中打开 ACE-DAW Transfer。

选择界面语言

窗口右上角可选 中文 或 English。切换会立即更新界面，保留已选工程和目录。下次打开时继续使用上次的语言。

把配乐从 ACE 转到 Nuendo

假设你要继续剪一份已经在 ACE Studio 保存的配乐：

  1. 在 ACE Studio 保存工程，把 .acep 文件拖入转换窗口，或点选择文件…。
  2. 在输出格式选 Nuendo 工程 (.npr)。输出位置默认是源工程所在目录，可以用选择目录…更改。
  3. 点开始转换。完成后点打开结果目录，在 Nuendo 打开生成的 NPR。Cubase 用户在第二步选择 CPR。
转换仅读写已保存的文件。转换期间可以关闭 DAW。每次运行使用独立结果目录。

选择格式与保留配色

先决定是打开一份独立工程，还是把配乐轨道加进手头正在剪辑的工程。

输出格式适用场景
CPR / NPR分别用于 Cubase / Nuendo。独立工程包含编排、媒体引用、轨道和标记。直接用对应宿主打开。
轨道 XML在已有 Cubase 或 Nuendo 工程中选择“文件 → 导入 → 轨道存档”，选择轨道并保留绝对位置。宿主提供媒体选项时选引用现有媒体。
ACEP选择已保存的 CPR、NPR 或轨道 XML，输出 ACE Studio 工程。打开结果里的 ACE项目.acep 继续编辑。

轨道色与标记色

从 ACE 新建原生工程时，最多可独立保存 40 种颜色，超出后使用相近色。按已有原生来源写回时，颜色受来源色盘影响。XML 导入已有工程时，目标工程控制显示颜色。

配色底板为什么是空的？

有自定义颜色时，XML 方案会附带 配色导入底板.npr。打开它后，再将同一目录的 XML 作为轨道存档导入。想直接打开配乐时，在转换工具选择 CPR 或 NPR。

把新的音乐传回 DAW

在 ACE Studio 保存修改后的 ACEP，再将其拖入转换工具。保留 transfer-map.json 和原工程，工具可利用映射写回匹配的原生字段。剪辑结构发生变化时，可按 ACE 时间线重新建工程。

声音、素材与故障处理

对画时可以先核对首尾切点、一个静音块、一段淡化和一个标记，再按需要试听插件链。

素材路径与缺失文件

可直接引用的 WAV 和视频继续留在原位置。跨电脑或从 Windows 换到 Mac 时，先转移素材并确保目标机器上的路径可用。缺失文件请先在源工程中重新链接并保存。转码、拼接或烘焙所需的新音频会放在结果目录。

轨道、片段与淡化

音频片段按绝对位置、时长和源偏移转换。轨道电平、片段增益、片段静音和默认 S 形淡化分别保存。默认曲线在 DAW 端为每段淡化写入 1,025 个点。工作范围以固定速度、4/4、48 kHz 工程和 24 fps 视频为准。

从 DAW 返回 ACE 的三个选项

反向转换可把支持的非默认淡化烘焙到独立音频。只迁移可用的静态混音和剪辑会把部分自动化、总线路由及不兼容处理列入报告，混音可能改变。仅保存可提取的 VST3 预置可用于先恢复剪辑、稍后处理插件。选项会自动记忆。

插件与转换结果

可识别的第三方 VST3 依赖相同组件身份及目标机器的扫描记录、许可与外部采样。工程级文件校验覆盖位置、媒体和支持的参数。具体插件音色及硬件路由还需在目标宿主试听。转换失败时查看窗口日志和结果目录中的 JSON。

分发包未进行 Apple 公证，Windows MSI 未使用发布者证书签名。请从项目发布页取得安装包。若 macOS 提示开发者无法验证，参阅Apple 的安全打开应用说明。
