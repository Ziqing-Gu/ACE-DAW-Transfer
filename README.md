# ACE-DAW Transfer

## 产品介绍 / About

在 ACE Studio、Cubase 和 Nuendo 之间离线迁移配乐工程。选择 CPR 或 NPR 可直接打开编排，选择 XML 可把轨道加入已有工程。程序读写已保存的文件，支持独立片段、媒体引用、标记和可编辑的默认 S 形淡化。

Move a score between ACE Studio, Cubase and Nuendo offline. Create an editable CPR or NPR, or import a track archive into an existing session. The converter reads saved files and preserves supported clips, media references, markers and default S-curve fades.
